# 🌙 睡了么（SleepShift）

> 一个以月亮为陪伴核心的睡眠体验 Android 应用。
> 通过睡眠时间、睡眠人格与虚拟时间体验，帮助用户重新认识自己的睡眠习惯。

**当前版本：0.3.25 Alpha 内测版**

---

## 📱 项目介绍

「睡了么」是一款面向睡眠体验的 Android 应用。

它不只是一个记录睡眠时间的工具，而是希望通过更具陪伴感的方式，让用户与自己的睡眠建立联系。

在应用中，你会拥有一轮属于自己的月亮，并通过睡眠目标、当前作息、睡眠人格等数据，逐渐形成属于你的睡眠画像。

---

## ✨ 当前已实现功能

### 🌙 月亮陪伴系统

* 独立月亮成长视觉
* 月亮呼吸光晕与点击交互
* 睡前向月亮道晚安
* 醒来后的「昨晚月亮观察」
* 睡眠状态与月亮状态关联

---

### 🧠 睡眠人格系统

根据：

* 当前睡眠时间
* 目标睡眠时间
* 作息规律程度
* 理想作息与现实作息之间的偏差

生成初步睡眠人格倾向。

目前为 Alpha 阶段，后续将扩展更多睡眠人格类型。

---

### ⏰ 睡眠目标管理

支持设置：

* 理想睡眠时间段
* 当前实际睡眠时间段

系统会自动计算：

* 理想睡眠时长
* 当前作息与目标之间的差距

这些数据将作为未来睡眠人格分析的重要依据。

---

### 🕰 虚拟时间体验

通过调整虚拟时间偏移，让用户体验：

* 不同时间节奏
* 睡眠前后的时间变化
* 更直观的睡眠环境反馈

---

### 💬 人格气泡互动

主页拥有漂浮的人格气泡：

* 自由漂浮
* 拖拽互动
* 物理碰撞效果
* 个性化碎碎念（持续开发中）

## 📜 开发理念

「睡了么」希望探索一种新的睡眠应用形式：

不是简单告诉你：

> “你今天睡了几个小时。”

而是希望让睡眠成为一个可以被感知、被理解、甚至被陪伴的过程。

愿每个人都能拥有一轮属于自己的月亮。 🌙
